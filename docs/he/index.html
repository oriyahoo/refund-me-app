עובד תוך דקות

פקודה אחת על שרת עם Docker. אשף בדפדפן עושה את השאר. חינם לחברה שלכם (רישיון).

# פקודה אחת: הגדרות, מפתח, הורדה, הפעלה
$ curl -fsSL https://raw.githubusercontent.com/oriyahoo/refund-me-app/main/install.sh | sh

# ואז פותחים את אשף ההתקנה
http://your-server:3855

# עדכון בהמשך
$ cd refund-me && docker compose pull && docker compose up -d

מה צריך

  • שרת לינוקס או מכונה וירטואלית עם Docker. 2 ליבות ו-2 GB זיכרון מספיקים למשרד קטן.
  • מסד נתונים: המובנה (עד כ-50 אנשים), או PostgreSQL,‏ SQL Server / Azure SQL,‏ MySQL או MariaDB.
  • כתובת HTTPS מול האפליקציה לשימוש אמיתי.
  • אופציונלי: שרת מייל, ו-Microsoft Entra ID או Google Workspace לכניסה אחודה.
