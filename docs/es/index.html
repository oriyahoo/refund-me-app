Inicio de sesión único (SSO)

Entra con la cuenta de trabajo que ya tienes

Conecta Microsoft Entra ID (Microsoft 365) o Google Workspace y tu gente entra con un clic. Ninguna contraseña nueva que recordar y nada nuevo que gestionar para TI.

  • ✓
    Se aplican tus reglas de accesoEl acceso se hace en Microsoft o Google, así que las reglas de tu empresa, como la verificación en dos pasos, también cubren Refund-Me.
  • ✓
    Solo tu organizaciónEl acceso con Microsoft está ligado a tu propio tenant, nunca a «cualquier cuenta de Microsoft», y solo entra quien está en la lista. Un compañero que aún no está espera a que un administrador o contable lo apruebe.
  • ✓
    Quien se va, queda fueraDesactiva la cuenta de trabajo de alguien y ya no podrá entrar con ella; desactívalo en Refund-Me y se cierra su sesión en todas partes a la vez.
  • ✓
    Sin quedarse fueraLos enlaces de un solo uso por email y las contraseñas siguen ahí para quien los necesite, y se pueden desactivar cuando el SSO funcione. Los administradores siempre pueden entrar, así que un SSO mal configurado no deja a todos fuera.

    Se configura en el asistentePega el ID y el secreto de la aplicación desde tu consola de administración de Microsoft o Google; la guía muestra exactamente dónde.

La seguridad, en palabras sencillas

Dinero y datos personales, protegidos

Los tickets llevan nombres, importes, dígitos de tarjeta y matrículas. Esto es lo que los protege.

Solo entra tu gente

Solo la gente de la lista puede entrar, con cuentas de trabajo de Microsoft o Google, un enlace de un solo uso por email o una contraseña. Los intentos de adivinar contraseñas se frenan automáticamente.

Una prueba para los cambios importantes

Nombrar un administrador, cambiar el acceso o el correo, restablecer los datos o cargar una copia exige un acceso reciente o la contraseña. Una sesión robada no basta.

Ver solo lo tuyo

Los empleados ven sus propios gastos, los responsables su equipo y contabilidad la empresa. Los asistentes de IA tienen exactamente los permisos de su dueño y pueden ser de solo lectura.

Los secretos siguen siendo secretos

Las contraseñas y claves guardadas se cifran, y la clave puede guardarse aparte de los datos. El usuario de base de datos de la app solo puede leer y escribir sus datos.

Nada pasa en silencio

Un registro de actividad de quién hizo qué, cuándo y desde dónde, que nadie puede editar ni borrar. Los demás administradores reciben avisos de cambios de configuración y de administradores.

Construido y operado con cuidado

Funciona como usuario normal, sin poderes extra. Las nuevas versiones de paquetes esperan dos semanas, cada paquete se verifica y las revisiones de seguridad independientes vienen con correcciones.

Instalación

En marcha en minutos

Un comando en un servidor con Docker. Un asistente en el navegador hace el resto. Gratis para tu propia empresa (licencia).

# un comando: ajustes, clave, descarga, arranque
$ curl -fsSL https://raw.githubusercontent.com/oriyahoo/refund-me-app/main/install.sh | sh

# luego abre el asistente de configuración
http://your-server:3855

# actualizar más adelante
$ cd refund-me && docker compose pull && docker compose up -d

Necesitas

  • Un servidor Linux o una máquina virtual con Docker. 2 núcleos y 2 GB de memoria bastan para una oficina pequeña.
  • Una base de datos: la integrada (hasta unas 50 personas), o PostgreSQL, SQL Server / Azure SQL, MySQL o MariaDB.
  • Una dirección HTTPS delante de la app para uso real.
  • Opcional: un servidor de correo, y Microsoft Entra ID o Google Workspace para el inicio de sesión único.
