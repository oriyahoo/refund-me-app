Security, in plain words

Money and personal details, protected

Receipts carry names, amounts, card digits and car plates. Here's what keeps them safe.

Only your people get in

Only people on the list can sign in, with Microsoft or Google work accounts, a one-time email link or a password. Password guessing is paused automatically.

Proof for big changes

Making an admin, changing sign-in or email settings, resetting data or loading a backup needs a fresh sign-in or the password. A stolen open session isn't enough.

See only what's yours

Employees see their own expenses, managers their team, accounting the company. AI assistants get exactly their owner's permissions, and can be read-only.

Secrets stay secret

Saved passwords and keys are encrypted, and the key can live apart from the data. The app's own database login can only read and write its data.

Nothing happens quietly

An activity log of who did what, when and from where, which nobody can edit or delete. Other admins are alerted to settings and admin changes.

Built and run carefully

Runs as an ordinary user with no extra powers. New package versions wait two weeks, every package is checked, and independent security reviews come with fixes.

Single sign-on (SSO)

Sign in with the work account you already have

Connect Microsoft Entra ID (Microsoft 365) or Google Workspace, and your people sign in with one click. No new password to remember, and nothing new for IT to manage.

  • ✓
    Your sign-in rules applyPeople sign in at Microsoft or Google, so your company's own rules, such as two-step verification, cover Refund-Me too.
  • ✓
    Only your organizationMicrosoft sign-in is tied to your own tenant, never "any Microsoft account", and only people on the list get in. A colleague who isn't on it yet waits for an admin or accountant to approve them.
  • ✓
    Leavers are outDisable someone's work account and they can no longer sign in with it; turn them off in Refund-Me and they're signed out everywhere at once.
  • ✓
    No lock-outsOne-time email links and passwords are there for those who need them, and can be switched off once SSO works. Admins can always sign in, so a broken SSO setup can't lock everyone out.
  • ✓
    Set up in the wizardPaste the app ID and secret from your Microsoft or Google admin console; the guide shows exactly where.

Log forwarding (SIEM)

Every action, in your SIEM as it happens

Send the activity log to Splunk, QRadar, Microsoft Sentinel, Wazuh, Graylog or Axiom, so your security team sees Refund-Me with everything else.

  • ✓
    Standard formatsSyslog (RFC 5424) over TLS, TCP or UDP, or HTTPS with JSON. Axiom is a ready choice: a dataset and a token, and you're done.
  • ✓
    Everything, with detailSign-ins, approvals, setting changes, emails and errors, with who, when and from which address. Passwords and keys never leave.
  • ✓
    Nothing lost quietlyWhile the collector is down, entries wait and are sent again. Anything that can't be sent is counted and recorded.
  • ✓
    Can't be switched off unseenTurning it on, changing it or stopping it asks the admin to confirm it's them, and the other admins are told.
  • ✓
    Tested before it's saved"Check and save" sends a test entry first, and the settings page shows whether entries are getting through.

Installation

Running in minutes

One command on a server with Docker. A setup wizard in the browser does the rest. Free for your own company (license).

# one command: settings, key, download, start
$ curl -fsSL https://raw.githubusercontent.com/oriyahoo/refund-me-app/main/install.sh | sh

# then open the setup wizard
http://your-server:3855

# upgrading later
$ cd refund-me && docker compose pull && docker compose up -d

You need

  • A Linux server or virtual machine with Docker. 2 CPU cores and 2 GB of memory are enough for a small office.
  • A database: the built-in one (up to about 50 people), or PostgreSQL, SQL Server / Azure SQL, MySQL or MariaDB.
  • An HTTPS address in front of the app for real use.
  • Optional: an email server, and Microsoft Entra ID or Google Workspace for single sign-on.
